Onboarding a Client

Summary: To add a new client to ade-catalog you need to: create their organization, connect to their analytics platforms, extract metadata, and import it. This guide covers each step.

Prerequisites

Before you begin, make sure you have:

Admin access An ade-catalog account with owner or admin role
Python 3.10+ Installed on the machine where you'll run the extraction. Download Python
ade-catalog repo Clone the repo and install dependencies:
git clone https://github.com/rbutinar/ade-catalog.git
cd ade-catalog
python -m venv .venv
.venv/bin/pip install -r requirements.txt # macOS/Linux
# or: .venv\Scripts\pip install -r requirements.txt (Windows)
Platform credentials Access to the client's analytics platforms. See details per platform below.
1

Create Organization

This step is done from the web UI. No terminal needed.

  1. Log in to ade-catalog as admin
  2. Go to Admin → Organizations
  3. Fill in name (e.g. "Acme Corp") and slug (e.g. "acme-corp"), then click Create
  4. Go to Admin → Users
  5. Create user accounts for the client and assign them to the new organization
2

Extract Metadata

This step runs from a terminal on any machine with Python and a web browser. The extractor connects to the client's platform APIs, downloads metadata, and saves it as JSON files locally.

Why a terminal? Platform APIs require interactive authentication (browser login). This cannot run from the web UI. After the first login, tokens are cached and subsequent runs don't need interaction.

Microsoft Fabric

What you need: The client's Azure AD tenant domain (e.g. acme.com) and an account with read access to their Fabric workspaces.

What it connects to: Microsoft Fabric REST API (api.fabric.microsoft.com) and optionally SQL endpoints for table schemas.

Step A: See what's available (no data extracted)

.venv/bin/python -m ade_catalog.platforms.fabric.extractors.api_extractor \
  --tenant acme.com --list --browser

Opens your browser for login, then prints a list of accessible workspaces.

Step B: Extract everything

.venv/bin/python -m ade_catalog.platforms.fabric.extractors.api_extractor \
  --tenant acme.com --all --extract-sql \
  --output ./my_extraction --browser

--all = all workspaces. --extract-sql = also pull table/column schemas. --browser = use browser auth (required when the tenant has conditional access).

Step C: Extract one workspace only

.venv/bin/python -m ade_catalog.platforms.fabric.extractors.api_extractor \
  --tenant acme.com --workspace "PRD-Analytics" \
  --output ./my_extraction --browser

Databricks

What you need: Workspace URL and a personal access token (PAT). Generate a PAT from Databricks → User Settings → Access Tokens.

What it connects to: Databricks REST API via the Databricks SDK.

# Set credentials (one-time)
export DATABRICKS_HOST=https://adb-12345.azuredatabricks.net
export DATABRICKS_TOKEN=dapi-xxxxxxxxxxxx

# Extract
.venv/bin/python -m ade_catalog.platforms.databricks.extractors.api_extractor \
  --output ./my_extraction

Power BI

What you need: The .pbip project folder (exported from Power BI Desktop via "Save as Power BI Project"). No API access or credentials needed.

What it connects to: Nothing — it parses local files.

.venv/bin/python -m ade_catalog.platforms.powerbi.importers.pbip_importer \
  --input ./path/to/MyReport.pbip \
  --output ./my_extraction

What gets created?

All extractors produce JSON files in the output directory:

./my_extraction/
  fabric/
    workspace_inventory.json
    WorkspaceName/pipelines.json, notebooks.json, ...
  databricks/
    notebooks.json, jobs.json, tables.json
  powerbi/
    datasets.json
3

Import into Catalog

Still from the terminal. This reads the JSON files from step 2 and loads them into the ade-catalog database, making everything searchable in the web UI.

# Import the extracted data into a named view
.venv/bin/python -m ade_catalog.ingest \
  --source ./my_extraction \
  --view "Acme Fabric"

This auto-detects which platforms have data and imports each one. Uses full-refresh: safe to run repeatedly — old data for this view is replaced.

Demo shortcut: To import the built-in demo data (no extraction needed):
.venv/bin/python -m ade_catalog.ingest --source demo
4

Browse the Catalog

Back to the web UI. The imported data is now available:

  1. Use the View selector (top right) to switch to the new view
  2. The Dashboard shows overview stats
  3. The Catalog lets you search and browse all objects
  4. Click any object to see its full detail (columns, measures, activities, etc.)
