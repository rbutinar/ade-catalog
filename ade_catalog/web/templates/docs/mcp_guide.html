MCP Server & AI Agents

What is MCP?

Model Context Protocol (MCP) is an open standard that allows AI assistants to interact with external tools and data sources. ade-catalog exposes its catalog as an MCP server, so any MCP-compatible AI (Claude Desktop, Agent SDK, custom agents) can search, browse, and trace lineage programmatically.

Endpoint

POST https://ade-catalog.vercel.app/mcp

Discovery info available via GET on the same URL.

Claude Desktop Configuration

{
  "mcpServers": {
    "ade-catalog": {
      "url": "https://ade-catalog.vercel.app/mcp",
      "headers": {
        "X-API-Key": "your-api-key"
      }
    }
  }
}

Available Tools

search_catalog

Search across all objects. Params: query, platform, object_type, limit

"Find all tables related to sales in Fabric"

get_object_detail

Get full metadata for an object. Params: object_type, object_id

"Show me details of pipeline ID 42"

list_platforms

List platforms with data in the catalog and their object counts.

get_dashboard_stats

Overview statistics: workspaces, notebooks, datasets, measures, etc.

get_lineage

Trace upstream/downstream lineage. Params: node_name, direction, max_depth

"What feeds into the gold_ft_sales table?"

Example Request

curl -X POST https://ade-catalog.vercel.app/mcp \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-key" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "search_catalog",
      "arguments": {
        "query": "sales",
        "platform": "fabric",
        "limit": 10
      }
    }
  }'
