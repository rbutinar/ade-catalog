Getting Started

What is ade-catalog?

ade-catalog is a cross-platform analytics metadata catalog. It imports metadata from your analytics platforms (Microsoft Fabric, Databricks, Power BI), builds cross-platform lineage, and provides a navigable web UI and MCP server for AI agents.

Think of it as a data dictionary on steroids — it knows what tables exist in your warehouses, what notebooks process them, what measures visualize them, and how they all connect.

Supported Platforms

Fabric
  • Workspaces
  • Warehouses + schemas/tables/columns
  • Lakehouses + tables
  • Pipelines + activities
  • Notebooks
Databricks
  • Workspaces
  • Notebooks + code analysis
  • Table lineage (read/write)
  • Jobs + task dependencies
  • Medallion layers
Power BI
  • Reports + datasets
  • Tables + columns
  • DAX measures
  • Relationships
  • PBIP file parsing

Key Concepts

Organization
A tenant in the system. Each client (e.g., "Acme Corp", "Contoso") gets their own organization with isolated data and users.
View
A snapshot of metadata within an organization. You might have "Production", "Dev", or "Production Fabric" views. Each scan creates or updates a view.
Extraction
The process of pulling metadata from a platform via its API. Produces JSON files that are stored in cloud storage.
Ingestion
The process of importing extracted JSON files into the catalog database, making them searchable and browsable.
Lineage
The dependency graph connecting objects across platforms. Shows how data flows from source tables through notebooks/pipelines to Power BI reports.
MCP Server
A Model Context Protocol endpoint that allows AI assistants (Claude, etc.) to query the catalog, search metadata, and trace lineage programmatically.
