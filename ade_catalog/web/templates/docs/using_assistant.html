✨ Using the Catalog Assistant

What it is

A chat panel, available on every page (the ✨ button, bottom-right), for asking natural-language questions about the catalog. It does not guess — it answers by calling the catalog's own search and lineage tools (the same ones exposed over MCP), so numbers and names come straight from the database.

Examples:

  • "How many reports are about sales?"
  • "Which tables feed the 'Total Revenue' measure?"
  • "List the Fabric pipelines in this catalog."

Navigating from answers

When the assistant names a specific object, it can offer a link straight to that object's detail page and its lineage view — click through instead of searching the Catalog yourself. Links open in a new tab so the chat stays open.

Scope: it only sees your active catalog

The assistant is bound to the organization and view you currently have selected (shown in the chat header). This is enforced by the app, not by the assistant's own judgement — it cannot be asked to look at another organization's or view's data. Switch org/view with the selectors in the top navigation, then ask again.

Tips

Full-page mode
Use the expand icon in the chat header for a wider, easier-to-read layout on long answers — click again to return to the side panel.
Broad questions take longer
A specific question ("what feeds measure X") answers in a few seconds. An open-ended one ("tell me everything about sales") may take longer, since the assistant explores with several searches before answering.
Fresh conversation
Use the ↻ (reset) button in the chat header to start over — useful if you're switching to an unrelated topic.
Not seeing the chat button?
The assistant needs an API key configured by an administrator (see Architecture). Without one, the panel explains this instead of showing the chat.
