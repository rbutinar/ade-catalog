Using the Catalog

Dashboard

The Dashboard gives you an overview of your catalog: total objects by platform, notebooks by layer, and measures by dataset.

Switching Views

Use the View selector in the top-right corner of the navigation bar to switch between different catalog views. Each view represents a scan or snapshot of one or more platforms.

Example: you might have a "Production Fabric" view and a "Dev Databricks" view, each with different data.

Searching

Go to Catalog and type in the search bar. Search is instant (HTMX) and matches object names, paths, and descriptions.

Tips:

  • Leave the search empty to browse all objects
  • Use the Platform dropdown to filter by Databricks, Power BI, or Fabric
  • Use the Type dropdown to filter by notebooks, tables, measures, pipelines, etc.
  • Search matches partial names — "sales" finds "FactSales", "sales_pipeline", etc.

Browsing the Tree

The catalog page also shows a hierarchical tree on the left:

  • Databricks: Workspace → Notebooks (click to expand)
  • Power BI: Report → Dataset → Tables & Measures
  • Fabric: Workspace → Warehouses/Lakehouses → Schemas → Tables

Click on any node to expand it and see its children. Click on a leaf object to view its details.

Object Details

Click on any object name (in search results or tree) to see its full detail page. Depending on the type:

Notebook

Path, language, layer, tables read/written

Dataset

Connection mode, tables, measures, relationships

Measure

DAX expression, complexity, format string

Table (PBI / Warehouse / Lakehouse)

Columns with data types, row count, source

Pipeline

Activities, types, source/sink, nesting

Warehouse / Lakehouse

SQL endpoint, workspace, schema browser
