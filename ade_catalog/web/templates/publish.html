Publish to shared prod

Push a local organization's catalog into the shared production Supabase, scoped to that org. Members of the org then see it on the hosted app via RLS. This is a local-operator admin tool (super-admin / postgres); a restricted-user publish is a separate future concern.

Always dry-run first. Apply writes to production. Large orgs take minutes (one row per round-trip) — for very large publishes prefer scripts/publish_org_to_prod.py --org <slug> --apply.
